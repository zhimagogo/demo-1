# v40 世界设定：256×256 的「余烬王国」

> 本文是 v40 世界扩张的设计基线：地图尺度、六个主题区域的故事背景、视觉语言、
> 地标与实现索引。区域数据（名称/坐标/半径/配色/故事文本）的唯一代码真相在
> `scripts/defs/WorldRegions.gd`，改设定请先改那里，再同步本文件。

## 一句话世界观

王国已经亡了十年。王城是最后一座还亮着灯的城市，城外的世界被旧战争、坠星与干涸的
古湖撕成六块互不相同的土地。玩家从主城出发，沿四条主路与探索小径走进这些区域，
把散落在野外的故事一件件捡回来。

## 尺度与方位

| 项 | v39 | v40 |
| --- | --- | --- |
| 可玩边界 | 128×128 米 | **256×256 米** |
| 网格 | 64×64 格 @2m | **128×128 格 @2m** |
| A* 覆盖 | 4,096 格 | 16,384 格 |
| 王城安全区 | 40×40 米（半边长 20） | 不变 |
| 主路尽头 | ±57 米 | **±121 米** |

- 方位约定与小地图罗盘一致：**-Z = 北，+X = 东，+Z = 南，-X = 西**
  （v40 修正了 `road_end_name` 旧版把 +Z 叫「北」的错位；夜潮播报方向随之与小地图一致）。
- 旧地图（±64m）内的一切位置保持不变：主城、湖泊 (37,-28)、瀑布 (44,-45)、
  旅人营地 (-31,12)、瞭望塔废墟 (-40,-35)、采石场 (39,28)。
  **新增内容全部落在扩张环带**，因此旧存档、旧测试与旧地标语义不受影响。
- 探索动线：四条主路从城门直通地图边缘，六个主题区域各由一条小径从主路岔出
  （`WorldLayout.TRAIL_SEGMENTS`，地面着色共用同一份折线）；**v40.1 起小径终点在
  landmark 前 8.5m 收住（正好停在区域石碑前）**，不再从地标道具群中间穿过去。
- 夜潮（含头目）不在地图边缘的 `road_end` 出生：大图上 121m 要走 40 秒而一夜只有 50 游戏秒，
  会「走到天亮」。实际集结点为 `WorldLayout.night_wave_origin`（同一条路、62m，即旧地图边缘距离），
  `road_end` 只保留为播报方向与测试锚点。

## 六个主题区域

### 1. 北境 · 霜语瀑布（frost）

- 位置：北偏东，圆心 (44, -60)，半径 24m（v40.1 微调，避免与星落矿坑圆重叠）；地标点 (33, -50)——水潭西岸。
- 现状基础：v12 的瀑布 → 寒潭 → 河流 → 湖泊水系原样保留，是全场唯一的高差景观。
- 视觉语言：冰蓝 + 青白。寒色针叶林、冰晶簇、雪斑、冷色灯笼；地面染色
  `Color(0.52, 0.68, 0.78)`（tint 0.72），强调色 `Color(0.70, 0.90, 1.00)`。
- 故事：王国最后一位霜语者把自己的名字溶进了这条河。潭水终年不冻，旅人若在水边
  喊出故人的名字，回声会慢半拍——那是霜语者在替你应答。
- 地标：许愿石堆祭坛、冰晶丛、跨河木栈道、冷色路灯。
- 玩法钩子（后续）：在水潭边「喊名字」交互（E）触发一次短增益或引出一只霜灵。

### 2. 东北 · 星落矿坑（mine）

- 位置：圆心 (94, -84)，半径 30m。
- 视觉语言：紫灰 + 冷铁。裸露岩层、矿轨与矿车、紫色发光矿晶、矿灯；地面染色
  `Color(0.40, 0.35, 0.48)`（tint 0.78），强调色 `Color(0.74, 0.58, 1.00)`。
- 故事：三百年前一颗星落在东岭，砸出这口深坑。矿工挖出的铁矿石夜里会自己发光，
  打成的剑锋利得能切开月光。矿脉枯了以后，坑底仍夜夜响起敲石声。
- 地标：KayKit 矿洞入口、矿轨与矿车、矿晶簇、木箱与矿灯。
- 玩法钩子（后续）：矿晶可采集为「星铁」，用于高阶建造或巨龙升级。

### 3. 东境 · 风吟麦海（wheat）

- 位置：圆心 (94, 4)，半径 30m。
- 视觉语言：金麦 + 暖黄。成排农田、风车、稻草人、干草堆、木栅栏；地面染色
  `Color(0.76, 0.62, 0.26)`（tint 0.70），强调色 `Color(1.00, 0.84, 0.44)`。
- 故事：王国尚在时，这里的麦子能养活十座城。农人散了，风车却没人敢停——老人们说，
  风车停下的那天，最后一批守粮人的魂就会迷路。
- 地标：风车（昼夜缓转的表现位）、农田阵列、稻草人、谷仓与栅栏。
- 玩法钩子（后续）：白天在麦田劳作可获得食物/金币；夜潮可能借麦浪掩护接近。

### 4. 南境 · 烬誓战场（battle）

- 位置：圆心 (4, 96)，半径 30m。
- 视觉语言：焦黑 + 余烬橙红。断旗、墓碑阵、破碎城墙、枯树、余烬光点；地面染色
  `Color(0.43, 0.32, 0.24)`（tint 0.74），强调色 `Color(1.00, 0.44, 0.26)`。
- 故事：「烬誓之战」打了七天七夜。败军把军旗折断插进土里，发誓来世再战。焦土至今
  不长麦子，只长一种红得像炭的花。夜里能听见铁器相击，走近却只有风。
- 地标：折断的军旗阵、墓碑、破碎城墙、武器架、余烬火盆（夜间最亮）。
- 玩法钩子（后续）：夜间在此刷新精英「余烬老兵」；拾取断旗可触发支线。

### 5. 西境 · 雾隐密林（forest）

- 位置：圆心 (-94, -4)，半径 30m。
- 视觉语言：深绿 + 苔青。高密度古树、蘑菇群、立石阵、林间祭坛、萤火；地面染色
  `Color(0.19, 0.34, 0.18)`（tint 0.68），强调色 `Color(0.52, 0.92, 0.64)`。
- 故事：密林里的树会记住每个进入者的名字。樵夫带走了斧头，带不走的是挂在枝头低声
  回响的呼唤。林心有一座苔封的石祭坛，供着无名的树灵。
- 地标：苔封石祭坛（绿色符文）、立石环、古树环、萤火灯。
- 玩法钩子（后续）：祭坛交互可换取「树灵祝福」；林中视野受限、适合伏击。

### 6. 西南 · 盐风沼地（swamp）

- 位置：圆心 (-86, 86)，半径 30m。
- 视觉语言：盐白 + 病态青绿。盐壳斑块、枯树、芦苇、半沉木船、鬼火；地面染色
  `Color(0.33, 0.40, 0.33)`（tint 0.74），强调色 `Color(0.60, 0.92, 0.78)`。
- 故事：古湖干涸后留下一片盐壳与枯树。传说盐风里裹着一支商队的名字：谁在沼地里听见
  驼铃，循声走去，就会走上三百年前的旧商道——再也没回来。
- 地标：半沉商船、盐壳、枯树与芦苇、青绿鬼火。
- 玩法钩子（后续）：鬼火可引路发现隐藏宝箱；沼地会周期性起雾降低视野。

## 王城与旧地标

- **王城 · 最后一座城**（`WorldRegions.CITY`）：40×40m 安全区，昼夜不熄的火炬。
  区域播报会显示城名，但不参与地面染色与植被改造。
- **旅人营地** (-31,12)：商队旧营地，篝火仍在——赶路人的落脚点。
- **瞭望塔废墟** (-40,-35)：王国边境的旧哨塔，如今只剩半截塔身。
- **采石人歇脚处** (39,28)：旧采石场，石堆与矿灯。
- **湖泊** (37,-28)：全图唯一的大湖，岸线石与浅滩；东岸新增搁浅小船与栈桥（小故事点）。
- **霜语瀑布** (44,-45)：v12 水系主景，现归入北境区域。

## 区域叙事如何呈现

1. **首次踏入**：HUD 顶部区域横幅（区域名 + 副标题），消息日志追加区域故事（lore），
   播放一次发现音效；`EventBus.region_discovered` 对外广播。
2. **再次踏入**：只弹横幅（不重复故事）。
3. **离开区域**：横幅淡出，`EventBus.region_exited` 广播。
4. **小地图**：六个区域以主题色半透明色块 + 强调色描边显示，并标注当前区域名。
5. **实体路标**：四座城门外各有一块指路石碑，六个区域入口各有一块区域石碑。
6. **场景表现（v40.1）**：地标道具统一 AABB 贴地并互相推离（`ScenePolishTest` 13 项把关）；
   **v40.2 氛围**：每区一盏粒子发射器（`RegionAmbience`，昼夜门控）+ 湖东岸栈桥/小船；风车扇叶缓慢自转；植被树干改灰褐、battle/swamp 用程序化枯树。
   地标脚下有 ground shader 的夯土地皮；雪/盐/焦土斑、余烬、芦苇减量换形；五区专属草色层；
   128~158m 外围林带补上地图边界与远山之间的过渡；瀑布崖体改为同材质岩脊（无黄色山体顶面）；
   远山用冷色乘算 + 远环山影；地面网格 560m + 地平雾毯。多机位验收图在 `artifacts/world40b/`。

## 美术资源

- 新增自然/建筑/道具模型来自 **KayKit Medieval-Hexagon-Pack**（作者 KayKit，
  CC0 1.0，<https://github.com/KayKit-GameAssets/KayKit-Medieval-Hexagon-Pack-1.0>）。
  与项目现有 KayKit 占位资源同作者同风格，共用 `hexagons_medieval.png` atlas。
- 程序化几何（冰晶、麦浪、墓碑、矿轨、鬼火等）由 `ThemedRegions` / `DecorationScatter`
  用 BoxMesh / CylinderMesh / SphereMesh 生成，不引入额外授权。
- 授权记录随素材写在 `assets/_PLACEHOLDER/README.md`。
